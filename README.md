# Light Security Kit

A lightweight security kit for WordPress and ClassicPress. It disables XML-RPC, hides the WordPress version, blocks the file editor, and applies simple performance tweaks. No complex configuration.

## Features

- Disable XML-RPC
- Hide WordPress version
- Disable file editor
- Clean up the `<head>`
- Block REST API for visitors (optional)
- Block user enumeration
- Disable emojis

## Installation

1. Upload the `light-security-kit` folder to `/wp-content/plugins/`.
2. Activate the plugin through the 'Plugins' menu.
3. Go to **Settings > Light Security** to configure the options.
